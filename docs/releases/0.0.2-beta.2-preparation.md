## What's New

Beta 2 makes conversations easier to pick up and more stable to navigate,
with individual photo actions on iPhone and more capable local agents on Mac.

- **Keep your place in longer conversations.** Desktop history loads more
  steadily, media previews reuse loaded images, and unread replies stay in
  order. iPhone chats reopen more reliably and handle scrolling and keyboard
  transitions more smoothly.
- **Expand agent details without losing your place.** iPhone trajectories open
  below their header without jumping to the end of the reply, and short chats
  stay above the composer when reopened.
- **Work in the folder you chose.** Local agents retain your workspace across
  follow-ups and resumed sessions. Owner-only macOS application automation is
  now available.
- **React to individual photos.** Each iPhone photo has its own reaction and
  deletion controls. Message menus preserve formatted text, emoji, and
  expanded content.
- **Pick up conversations with less clutter.** History recovery avoids repeat
  uploads and preserves original dates on iPhone. Read messages clear their
  delivered iPhone notifications, and Agent subsessions open more reliably.

This is draft release copy. Publish the photo-action highlight only after the
server rollout and live mutation checks below pass. The desktop in-app summary
uses four curated highlights for this exact version. Full GitHub and updater
notes must come from the [matching changelog entry](../../CHANGELOG.md#002-beta2---2026-09-14).

## TestFlight: What to Test

Draft for iOS 0.0.2 (2), after release qualification:

- Reopen long chats and Agent subsessions, scroll older history, jump to the
  latest message, and open or dismiss the keyboard. Check that your reading
  position stays stable and replies remain above the composer.
- Expand and collapse agent trajectories, including in short chats. Check that
  details stay below the header and opening them preserves the tapped position.
  Repeat with the keyboard open: trajectory controls should keep it open, while
  tapping blank conversation space should dismiss it.
- Long-press text and individual photos. Try photo reactions and deletion,
  repeated menus, and returning to the keyboard. Check that each action affects
  the selected photo and that formatted content keeps its layout.
- Open chats from notifications, read their messages, and return to
  Notification Center. Check that read notifications disappear while newer
  unread messages and unread threads remain.
- Revisit synchronized older conversations. Check their original dates and
  watch for repeated history or stale deleted photos.

### Horizontal session-entry follow-up

The user reported a small sideways movement affecting both incoming and outgoing
messages while the header and composer remain fixed. The reveal guard checked
only vertical measurements, so a late horizontal inset change could occur after
history became visible. It now includes the viewport width and horizontal scroll
position plus the content's left edge and width in its stability check. Existing
vertical settling, the fade, and the bounded 20-frame fallback remain unchanged.

A synthetic late-inset regression reproduces a 2-pixel shift on the original
source in both WebKit and Chromium. With the correction, both message edges stay
within 1 pixel after reveal. All eight session-entry browser tests pass across
those engines, including cold hydration, rapid returns, and delayed images.
This proves the corrected settling case; native confirmation of the user's
specific report remains pending. No native installation was replaced.

### Native session-jitter acceptance follow-up

The native preview still showed apparent horizontal movement and vertical jitter
following the initial horizontal-stability guard. Numeric-only local captures
confirmed 5-pixel vertical movement after history became visible, while recorded
horizontal message geometry remained stable. The exact horizontal rasterization
cause is not established by those geometry samples.

The follow-up removes the whole-history opacity fade and repairs late tail
alignment in the same mutation microtask as the virtual extent update. This
covers Human as well as Agent histories, attaches after cold hydration, and
suspends automatic tail resizing while a disclosure owns the reading position.
A five-pixel growth regression fails before the fix for both modes in WebKit and
Chromium and passes afterward. All 32 related browser cases and 2,915 desktop
unit tests pass, together with typecheck, lint, and the production web build.
Review retained the existing disclosure motion guard and checked observer
cleanup, cold hydration, reading above the tail, and reduced motion. The user
reported that the updated production-connected Mac preview looks better. This
feedback does not establish that every long-session or scrolling case is
defect-free.
