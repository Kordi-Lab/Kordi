## What's New

Beta 3 makes group planning, voice messages, discussions, and Agent routing more
direct and reliable.

- **Plan together with PiP.** The built-in group planning agent creates shared,
  confirmable plan cards from conversation context and keeps their participants
  and status current.
- **Send voice messages immediately.** Mac and iPhone send recordings before
  transcription finishes, and iPhone hold-to-talk begins without the previous
  delay.
- **Quote or open a discussion.** Clearer reply actions, refined message tails,
  and corrected discussion spacing make related messages easier to follow.
- **Keep Agents on an available provider.** Stale model routes now fall back to
  a configured provider and compatible model, including ChatGPT OAuth, instead
  of showing a false no-provider error.

The desktop in-app summary uses four curated highlights for this exact version.
Full updater and GitHub release notes must use the matching changelog entry.

## TestFlight: What to Test

- Create and update a PiP plan in a group. Confirm that participant avatars,
  scheduling requirements, votes, confirmation, and subsequent updates remain
  consistent across Mac and iPhone.
- Record voice messages on iPhone and Mac. Confirm that sending is immediate,
  transcription arrives later without duplicating or replacing the recording,
  and failed messages stay in the correct order.
- Quote messages and open discussions on both platforms. Confirm that reply
  context remains clear and discussion indicators do not add empty vertical
  space.
- Switch Agent models and mention an Agent in a group while only one provider is
  configured. Confirm that Kordi selects that provider and a compatible model
  automatically, without a no-provider notice.
- Pin and unpin chats, send saved stickers, attach files on Mac, and reopen the
  conversation on another device. Confirm stable ordering and presentation.
