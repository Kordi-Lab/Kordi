# Kordi 0.0.2 Beta 5 release preparation

Prepared on October 13, 2026. Status: release metadata prepared; not published.

| Platform | Version | Build or tag |
| --- | --- | --- |
| macOS | `0.0.2-beta.5` | Proposed tag `V0.0.2.beta5` |
| iOS | `0.0.2` | Proposed build `5` |

This candidate replaces `0.0.2-beta.4`. That version was built, signed, and
published to the acceptance channel only, then withdrawn after acceptance
testing showed that the model picker did not offer GPT-6 Sol or GPT-6 Luna.
Its immutable objects stay in release storage, so the corrected build uses a
new version and build number.

The release commit is the merge of this metadata change. The tag, GitHub
release, signed desktop artifact, iOS archive, App Store upload, and product
deployment remain separate gated operations. This preparation does not reserve
the iOS build number or publish an artifact.

## What's New

Beta 5 adds shared documents, connectors, and account memory, and reorganizes
chats around projects and agent conversations.

- **Work on documents together.** Markdown and HTML documents open in a native
  reader on Mac and iPhone. On Mac they open in tabs beside the chat with a
  rich editor, live co-editing, comments, and reactions. Owners can share a
  public link.
- **Ask an agent inside a document.** A mention in a comment gets a reply in the
  thread, and a delegated agent can edit the document.
- **Connect your tools.** Connectors give agents access to Google Calendar,
  Gmail, GitHub, and Slack with consent and approval prompts.
- **Review what Kordi remembers.** Account memory can be reviewed, edited,
  deleted, or switched off, and groups can keep shared memories.
- **Organize chats.** Projects, a separate Agent Chats area, a compact Threads
  layout, and stacked pins.

The desktop in-app summary uses four curated highlights for this exact version.
Full updater and GitHub release notes must use the matching changelog entry.

## TestFlight: What to Test

- Open a Markdown and an HTML document from a group on iPhone and Mac. Confirm
  that reactions and comments appear on the other device and on the public
  link, and that two Macs can edit the same document at once.
- Mention an agent in a document comment with a model provider signed in.
  Confirm that the reply appears in the thread and that a delegated edit
  changes the document.
- Connect a provider under Connectors and ask an agent to use it. Confirm the
  consent and approval prompts.
- Review, edit, and delete a memory, then switch memory off.
- Create a project, move chats into it, switch to the Threads layout, and pin
  several messages.
- Sign up with a new email and confirm the verification step.

## Validation record

- Shared documents: reader, editor, co-editing, comments, reactions, and public
  links exercised manually on two Mac instances, an iPhone simulator, and a
  browser against a task-owned backend.
- Comment-triggered agent runs: routing verified up to the missing-provider
  failure on the test backend. A real model reply or edit has not been
  exercised.
- Required CI passed on every merged pull request in this range.

Before publication, rerun the canonical repository validation, migration
gates, release metadata tests, English and privacy checks, and whitespace
validation. Verify that both the app and share extension report iOS `0.0.2`
build `5`. Any source change after final qualification requires a new
candidate.
