# Kordi 0.0.1-beta.5 Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to execute this production release task-by-task.

**Goal:** Publish Kordi Desktop `0.0.1-beta.5` from latest `origin/main` and update the production backend on `kordi-product` only if the main release contains backend/runtime changes not already deployed.

**Architecture:** Use a clean release worktree from `origin/main`, bump package/Tauri versions, verify, deploy backend in-place to the existing product VM/k3s service when needed, then build and create a GitHub prerelease with the DMG artifact. Product data remains on the existing Postgres StatefulSet/PVC; no rehost or cluster recreation.

**Tech Stack:** pnpm, Tauri v2, Rust/Cargo, k3s on GCE, GitHub Releases.
