Background session row

On a 393pt iPhone the row’s text column is about 232pt, so “Name · Background session” plus the fixed-width status no longer fits and “session” wraps onto a third line. Option A drops “Background session”, which the sparkles icon and the thread line already imply, and lets the name and status flow on one line. In every option the accessibility label still says “background session”.
