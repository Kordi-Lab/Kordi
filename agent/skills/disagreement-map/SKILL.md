# Super Collaboration Disagreement Map

## Overview

Create a Deliberation map: turn vague disagreement into a concrete map of what is settled, what is unresolved, and what evidence or preference would resolve it.

## The Process

### Step 1: State Agreement
Name the shared goal, accepted facts, or common constraint.

### Step 2: Name Open Disagreement
Name the smallest concrete unresolved point.

### Step 3: Classify the Disagreement
Choose one:
- fact/evidence disagreement
- preference/value disagreement
- risk tolerance disagreement
- priority/scope disagreement
- ownership/process disagreement

### Step 4: Identify What Would Resolve It
Choose the needed resolution move:
- more evidence
- an owner/DRI decision
- a vote
- a consensus check
- escalation
- explicit tradeoff acceptance

## Rules

- Do not exaggerate disagreement.
- Do not call it consensus if only one participant has spoken.
- If two participants are optimizing for different criteria, name the criteria.
- Prefer one targeted clarifying question over a long list.

## Output Shape

```text
Agreement: <shared ground>
Open disagreement: <smallest concrete unresolved point>
Disagreement type: <type>
What would resolve it: <evidence/process/person needed>
```
