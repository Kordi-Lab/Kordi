# Browser behavior parity audit

Initial audit reference: desktop commit `103f9bf5d`. The branch was subsequently rebased onto main commit `5676f9fda` when the web workspace was extracted. The browser mounts the same application and context-specific controls. This document distinguishes implemented behavior from validation and remaining native dependencies; a shared component alone does not establish parity.

## Confirmed remaining desktop differences

1. **Agent message Fork is not implemented in the browser runtime.** The visible transcript action is offered by [useChatForkModel](../../desktop/src/pages/useChatForkModel.ts). Its handler reports an actionable desktop-required error in the browser. [useDesktopSessionController](../../desktop/src/features/chat/useDesktopSessionController.ts) requires the native `desktop_chat_fork_session_from_message` command. The existing hosted fork-recording API publishes metadata after the native snapshot exists; it is not an authoritative browser fork implementation. A server-backed snapshot/copy workflow is needed to claim parity.
2. **Show in Finder cannot reveal the user's filesystem in a standard browser.** The file context menu exposes it in [transcriptFileAttachmentLink](../../desktop/src/kordi-app/components/transcriptFileAttachmentLink.tsx); [attachmentDesktopActions](../../desktop/src/features/chat/attachmentDesktopActions.ts) invokes `desktop_reveal_in_finder`. The browser keeps the menu item disabled with an explanation pointing to the desktop app. A browser download is available through Save As, but this does not reveal a native Finder location.
3. **Agent-local artifacts and directory browsing need a connected-host file service.** [ArtifactInspector](../../desktop/src/pages/ArtifactInspector.tsx) can preview uploaded cloud files. The native folder route is `desktop_chat_artifact_directory`; path-only source files are not uploaded automatically by the browser. The browser must not fetch arbitrary paths or imply that a file on a remote agent's disk is local.
4. **Native memory import and native transcription remain different.** [Memory import](../../desktop/src/features/memory/memoryImportClient.ts) discovers local instruction files and invokes a native extractor. [Voice playback/transcription](../../desktop/src/kordi-app/components/voiceMessage.tsx) only enables on-device transcription in the native shell. Browser file selection and an authorized hosted extraction/transcription service would be required; no fake extraction is supplied.
5. **Legacy native message convergence is not fully reproduced.** The native [message mirror reconciler](../../desktop/src-tauri/src/canonical_sessions/commands/message_mirror.rs) validates exported local intent against wire records, rewrites references, and invalidates native context caches. Browser reconciliation currently accepts only matching request provenance. Native title-notice migration commands are skipped in [legacyCloudGroupTitleNoticeDesktop](../../desktop/src/features/cloud/legacyCloudGroupTitleNoticeDesktop.ts). Mixed historical desktop/cloud datasets require acceptance and equivalent provenance handling before claiming historical parity.
6. **Local runtimes, shell tools and filesystem slash commands are not browser runtimes.** Existing native sessions, workspace tools and local provider processes remain desktop-owned. Hosted routes can be used where the product already offers them; a browser adapter cannot safely fabricate a local process or successful native tool result.

## Release acceptance still needed

- Use two development accounts against an isolated/shared development backend to verify group creation, invitations, edits/deletion, reactions, unread state, revocation, and reconnect across native and browser clients.
- Exercise a real hosted agent with provider setup, long streaming response, cancellation/retry, files, memory, task/artifact publication and organization switching.
- Exercise real two-party audio/video media and browser permission failures; then verify document editing and shared links between those accounts.
- Decide and implement native-dependent workflows above before describing the browser as behaviorally identical to desktop. These limitations are not resolved by preserving their visual controls.
